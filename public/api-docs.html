API Reference

REST API for the Intelligent Accelerators desktop application. All endpoints return JSON.

REST / JSON OAuth 2.0 Password Grant Laravel 12 · Passport v13 31 tests · 80 assertions

Base URL & Headers

All API requests must include the following headers.

Base URL 
https://<your-domain>/api
Required Headers 
Content-Type:  application/json
Accept:         application/json

// Protected endpoints additionally require:
Authorization: Bearer <access_token>
X-Mac-Address: AA:BB:CC:DD:EE:FF
Device Binding: Tokens are bound to the MAC address used at login. Every protected request must send the same MAC via X-Mac-Address. A mismatch forces an immediate session revoke and returns mac_mismatch.
The Accept: application/json header is required so Laravel returns JSON errors instead of HTML redirects.

Error Codes

All error responses return a JSON body with a message field, and optionally an errors object.

Status Meaning Common Cause
200 OK Request succeeded.
401 Unauthorised Invalid credentials or expired / revoked token.
403 Forbidden Email not verified, or account status is pending, disabled, deactivated, or rejected.
422 Unprocessable Validation failed. Check the errors object.
500 Server Error Unexpected server-side error.
401 mac_mismatch Device Mismatch The X-Mac-Address header does not match the address bound at login. Token is immediately revoked.
401 mac_unbound Unbound Token Token has no MAC binding. Token is revoked. Log in again.
422 mac_missing MAC Missing X-Mac-Address header was not sent with a protected request.

Login

Authenticates a user and returns an OAuth2 access token and refresh token.

POST /api/auth/login No auth required
FieldTypeDescription
email* string Registered email address.
password* string Account password.
mac_address* string Hardware MAC address of the machine. Accepted formats: AA:BB:CC:DD:EE:FF, AA-BB-CC-DD-EE-FF, or AABBCCDDEEFF. The token is permanently bound to this address.
Example Request 
POST /api/auth/login
Content-Type: application/json
Accept: application/json

{
  "email":       "jane@example.com",
  "password":    "your-password",
  "mac_address": "AA:BB:CC:DD:EE:FF"
}
200 OK 401 / 403
200 — Success 
{
  "token_type":    "Bearer",
  "access_token":  "eyJ0eXAiOiJKV1...",
  "refresh_token": "def50200abc123...",
  "expires_in":    31536000,
  "user": {
    "id":    5,
    "name":  "Jane Smith",
    "email": "jane@example.com"
  }
}
401 — Wrong credentials 
{ "message": "Invalid email or password." }
403 — Account not active (examples) 
// Email not verified
{ "message": "Please verify your email address before signing in." }

// pending
{ "message": "Your account is awaiting admin approval." }

// disabled
{ "message": "Your account has been temporarily disabled. Please contact support." }

// deactivated / rejected
{ "message": "Your account has been deactivated. Please contact support." }

Refresh Token

Exchanges a valid refresh token for a new access token and refresh token pair. The old refresh token is invalidated.

POST /api/auth/refresh No auth required
FieldTypeDescription
refresh_token* string The refresh token received from login or a previous refresh.
mac_address* string The MAC address of the device. Must match the value used at login. The new token will be bound to this address.
Example Request 
POST /api/auth/refresh
Content-Type: application/json
Accept: application/json

{
  "refresh_token": "def50200abc123...",
  "mac_address":   "AA:BB:CC:DD:EE:FF"
}
200 — Success 
{
  "token_type":    "Bearer",
  "access_token":  "eyJ0eXAiOiJKV1...",
  "refresh_token": "def50200xyz456...",
  "expires_in":    31536000
}
401 — Invalid / expired 
{ "message": "Invalid or expired refresh token." }

Logout

Revokes the current access token and its paired refresh token. The token cannot be used after this call.

POST /api/auth/logout 🔒 Requires Auth
Both the access token and paired refresh token are revoked. The user must call login again to obtain new tokens.
Example Request 
POST /api/auth/logout
Authorization: Bearer eyJ0eXAiOiJKV1...
X-Mac-Address: AA:BB:CC:DD:EE:FF
Accept: application/json
200 — Success
{ "message": "Logged out successfully." }

Current User

Returns the profile of the currently authenticated user.

GET /api/auth/me 🔒 Requires Auth
Example Request 
GET /api/auth/me
Authorization: Bearer eyJ0eXAiOiJKV1...
X-Mac-Address: AA:BB:CC:DD:EE:FF
Accept: application/json
200 — Success
{
  "id":           5,
  "name":         "Jane Smith",
  "email":        "jane@example.com",
  "organization": "Emergent Consulting Inc.",
  "designation":  "Data Analyst",
  "status":       "approved"
}
